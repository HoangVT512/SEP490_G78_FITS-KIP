MyProject – Setup Guide
This document provides instructions for setting up the environment and running the project **Web API (.NET)** + **React Web** + **React Native Mobile** in **Visual Studio Code**.
---
### 1. Environment Setup
## 1.1. Install Git
- Download from: https://git-scm.com/downloads
- After installation, check version:
  git --version

## 1.2. Install Node.js and npm
- Download from: https://nodejs.org (choose the LTS version, e.g., v18+).
- Verify installation:
  node -v
  npm -v

## 1.3. Install .NET 8 SDK
- Download from: https://dotnet.microsoft.com/en-us/download/dotnet/8.0
- Verify installation:
  dotnet --version

## 1.4. Install Visual Studio Code
- Download from: https://code.visualstudio.com/

## 1.5. Install Extensions for VS Code
- Open VS Code → press Ctrl+Shift+X → search and install:
  - C# (ms-dotnettools.csharp)
  - C# Dev Kit (ms-dotnettools.csdevkit)
  - REST Client or Postman (for API testing)
  - ES7+ React/Redux/React-Native snippets
  - Prettier - Code formatter

## 1.6. Install Expo CLI (for mobile)
- Open terminal and run:
  npm install -g expo-cli
- Verify installation:
  expo --version"# System-Manage-Maintenance-And-Repair-For-Factory"
